# miniQSAR-solublity
Небольшой проект в области QSAR направлен на прогнозирование растворимости молекул с использованием алгоритмов машинного обучения.

# Почему я это сделал?
Я создал этот проект для олимпиады Open Doors

Да, это простой проект, но он демонстрирует вашу способность быстро учиться.

Если раньше исследователю приходилось проводить дни в библиотеках, то теперь, в эпоху искусственного интеллект
Сегодня данные предоставляют нам дорожную карту внедрения ИИ, позволяющую сократить этот путь Именно здесь в игру вступает творческое мышление
А также роль институтов, способствующих развитию этого творческого начала.
